# `se` Editor Basics

`se` is modeless: ordinary typing inserts text, and editor actions are available through control keys, function keys, the menu bar, and the command prompt.

## Common Keys

| Key | Action |
| :--- | :--- |
| `Esc` | Open command prompt |
| `^O` / `^S` | Save |
| `^X` | Exit buffer/editor |
| `^W` | Search |
| `^K` | Cut selected text, or cut current line |
| `^U` | Paste last cut text |
| `^J` | Justify paragraph |
| `^Z` | Undo |
| `^G` | Help |
| `Alt+T` | Toggle table mode |
