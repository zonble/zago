# TMD (Text Music Description) Music Support

`zago` features first-class support for editing, browsing, structuring, and exporting [TMD (Text Music Description)](https://github.com/zonble/TmdSwift) music score files (`.tmd`).

---

## 🎵 What is TMD?

TMD is a lightweight, human-readable plain-text musical notation format. It allows composers, arrangers, and musicians to write multi-track melodies, numbered musical notation (jianpu 簡譜), and chord progressions directly in a text file.

A typical TMD score file looks like:

```tmd
::SCORE::
** My Song **

!= 120
?= C
<4/4>

-> Intro
-> Verse
-> Chorus
-> #

Intro:Piano@|0|{
    <4*>
    [C] 1 3 5 1' | [G] 5, 7, 2 5 | [Am] 6, 1 3 6 | [F] 4, 6, 1 4 |
}

Verse:Piano@|0|{
    <4*>
    [C] 1 - 3 - | [G] 5 - 7 - | [Am] 6 - 1' - | [F] 4 - 6 - |
}

Chorus:Piano@|0|{
    <4*>
    [F] 4 6 1' - | [G] 5 7 2' - | [Em] 3 5 7 - | [Am] 6 1' 3' - |
    [Dm] 2 4 6 - | [G] 5 7 2' - | [C] 1' - - - |
}
```

## ✨ Features in `zago`

### 1. Syntax Highlighting & Outline Navigation
* **Syntax Highlighting**: Highlights `::SCORE::`, song title `** Title **`, tempo directives `!= 120`, keys `?= C`, time signatures `<4/4>`, subdivisions `<4*>`, scale degree numbers `1-7`, octaves (`1'`, `1,`), accidentals (`#`, `b`), chords (`[C]`, `[Am7]`), and block comments `/* ... */`.
* **Document Outline (`⌥\` / `M+\`)**: Jump across song sections directly from the outline dialog (e.g. `Intro (Piano)`, `Verse (Piano)`, `Chorus (Piano)`).
* **Next / Previous Section (`⌥]` / `⌥[` / `M+]` / `M+[` )**: Move directly between score section declarations.

### 2. Contextual TMD Menu
When opening a `.tmd` file, the top **MenuBar** automatically displays a dedicated **TMD** menu between the drawing menus and Help:

```text
TMD
├── Export MIDI
├── Export MusicXML
├── Export LilyPond
├── Export ABC
├── Export WAV (macOS only)
├── ---
├── Score Template
├── Paragraph (Verse)
└── Chord Progression
```

### 3. Multi-Format Exporting
You can compile and export the active `.tmd` buffer into various notation and audio formats directly from the editor:

| Format | Target Extension | Description | Supported Platforms |
|:---|:---|:---|:---|
| **MIDI** | `.mid` | Standard MIDI file for DAWs and synthesizers | macOS, Linux, Windows |
| **MusicXML** | `.xml` | W3C MusicXML (Partwise) for MuseScore, Sibelius, Finale, Dorico | macOS, Linux, Windows |
| **LilyPond** | `.ly` | LilyPond engraving source file for PDF/SVG sheet music | macOS, Linux, Windows |
| **ABC** | `.abc` | ABC notation for web tunebooks and folk music renderers | macOS, Linux, Windows |
| **WAV** | `.wav` | Rendered audio generated by system synthesizer (AudioToolbox) | macOS |

Each export command prompts for a destination path (defaulting to current file path with target extension) and reports progress or error details in the status bar.

### 4. Reusable Snippets
Insert standard score and paragraph templates without memorizing header syntax:
* **Score Template**: Complete header with `::SCORE::`, tempo, key, meter, arrangement order, and starter sections.
* **Paragraph (Verse)**: Instrument section declaration `Section:Instrument@|0|{ ... }` with 4-subdivision measure grid.
* **Chord Progression**: Clean chord backing template.

### 5. In-Editor Quick Reference
Press `F1` or open **Help -> TMD Quick Reference** (`:help-tmd` or `:tmd-reference` in command prompt) to open a searchable, scrollable reference document covering all TMD syntax rules, numbered notation modifiers, accidentals, chords, and playback orders.
