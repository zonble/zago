zago Web Virtual OS

zago is running with a full POSIX-compatible Virtual File System (VFS) in WebAssembly.

Useful Commands & Shortcuts:

  • :dir or :ls : Open interactive Directory Browser for subfolders
  • Ctrl + O : Save current buffer to IndexedDB VFS
  • Ctrl + X : Exit editor / buffer
  • ESC ESC : Toggle Canvas Mode (draw boxes, arrows, and tables)
  • Ctrl + G : Open help / command list
