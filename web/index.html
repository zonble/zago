🐢 zago

GitHub

Terminal editor to work with AI-generated text diagrams, using purely keyboard.

Why zago?

  • AI brings text diagrams to you for planning, system design, and architecture, but they are hard to edit again in standard editors.
  • Text diagrams in Markdown files are already an integral part of AI prompts and documentation workflows.

How?

  • Canvas mode editing: Move the cursor freely anywhere in the 2D text canvas without inserting empty lines or spaces manually.
  • Table mode: Edit text inside ASCII/Unicode tables and boxes seamlessly without breaking or shifting surrounding frames.
  • Quick drawing commands: Commands like BOX, LINE, and VLINE let you draft complete architecture diagrams in seconds.
  • CJK characters aware: Fullwidth CJK characters and emojis are measured with precise display widths and laid out perfectly in boxes.
  • Editor LOGO Engine: Built-in turtle graphics, macros, and scriptable text transformations.

Supported Platforms

  • macOS Linux Windows
  • UTF-8 Terminals WebAssembly

zago Web Virtual OS

zago runs with a POSIX-compatible Virtual File System (VFS) in WebAssembly.

Useful Commands & Shortcuts:

  • :dir or :ls : Open interactive Directory Browser for subfolders
  • Ctrl + O : Save current buffer to IndexedDB VFS
  • Ctrl + Q or Ctrl + X : Exit editor to mini-shell (type zago to return)
  • F8 : Toggle 2D Canvas Mode (draw boxes, arrows, and lines)
  • F7 : Toggle Table Mode
  • Ctrl + G : Open help / command list
