Welcome to zago on WebAssembly!

zago is a lightweight terminal text editor with powerful plain-text diagramming and built-in Editor LOGO.

Useful Shortcuts:

  • Ctrl + O / Cmd + S : Save buffer
  • Ctrl + X : Exit editor
  • Ctrl + G : Open help / command list
  • ESC ESC : Toggle Canvas Mode (draw boxes, arrows, and tables)
  • Ctrl + T : Spell check / suggestions
