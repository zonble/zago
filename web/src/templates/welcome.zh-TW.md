# zago 互動式新手教學

提示：請使用鍵盤與本文件進行互動。
方向鍵 / Page Up / Page Down 可移動游標。

## 畫布模式

```
┌────────┐          ┌────────┐
│        │          │        │
│  起點  x          │  終點  │
│        │          │        │
└────────┘          └────────┘
```

- 將游標移動到「x」的位置。
- 按下 F8 進入畫布模式（Canvas Mode）。
- 按住 Shift + 右方向鍵（▶）開始畫線。
- 繼續按住右方向鍵延伸線條。
- 按下 Ctrl + 方向鍵 或 Ctrl + Shift + 方向鍵 可繪製帶箭頭的線條。
- 按下 F1 開啟頂部選單，可在「框線」選單中切換框線樣式。
- 再次按下 F8 即可退出畫布模式。

## 表格模式

```
┌────────────────┬────────────────┬────────────────┐
│ 在此按下 F7    │                │                │
├────────────────┼────────────────┼────────────────┤
│                │                │                │
└────────────────┴────────────────┴────────────────┘
```

- 在任一儲存格內按下 F7 進入表格模式（Table Mode）。
- 進入後您可以任意編輯儲存格內的文字，完全不會破壞或擠歪表格格線。
- 再次按下 F7 即可退出表格模式。

## LINE（水平連接線）指令

```
┌────────┐          ┌────────┐
│        │          │        │
│  起點  │          │  終點  │
│        ├──────────┤        │
└────────┘          └────────┘
┌────────┐          ┌────────┐
│        │          │        │
│  起點  x          │  終點  │
│        │          │        │
└────────┘          └────────┘
```

- 按下 ESC 鍵可開啟指令列。
- 再次按下 ESC 可關閉指令列。
- 將游標移動至「x」的位置。
- 按下 ESC，輸入「LINE」並按下 Enter（不分大小寫）。
- 系統會自動朝右方尋找方塊並畫好連接線！

```
┌────────┐   ┌────────┐ 
│        │   │        │ 
│  起點  │   │  終點  │ 
│        │   │        │        
└───x────┘   └────┬───┘ 
                  │
                  │
                  │
┌────────┐   ┌────┴───┐ 
│        │   │        │ 
│  起點  │   │  終點  │ 
│        │   │        │ 
└────────┘   └────────┘ 
```

- 將游標移動至「x」的位置。
- 按下 ESC，輸入「VLINE」並按下 Enter。
- 系統會自動向下尋找方塊並垂直連接！

## 自訂框線與箭頭風格

您可以在畫線指令後方加上風格定義參數：

- LINE ->>
- LINE =~>
- VLINE <|+|>

語法格式：[起點箭頭][線條風格][終點箭頭]

### 框線風格代碼

- 單線（Single）：-
- 雙線（Double）：=
- 粗線（Heavy）：+
- ASCII 線條：A
- 雙虛線（Double Dash）：--
- 粗雙虛線（Heavy Double Dash）：++
- 三虛線（Triple Dash）：---
- 粗三虛線（Heavy Triple Dash）：+++
- 四虛線（Quadruple Dash）：----
- 粗四虛線（Heavy Quadruple Dash）：++++

### 箭頭風格代碼

- ASCII 箭頭：< 或 >
- 實心箭頭（Solid）：<< 或 >>
- 帶軸箭頭（Stemmed）：<~ 或 ~>
- 空心箭頭（Hollow）：<| 或 |>
- 小型箭頭（Small）：<. 或 .>

## BOX 與 DRAWBOX（方塊繪製）指令

試試看在 ESC 指令列輸入以下指令繪製方塊：

- BOX "你好"       ; 繪製一個包含「你好」文字的方塊
- DRAWBOX "方塊"   ; 直接在當前游標位置覆蓋繪製方塊（不推擠既有文字）
- BOX 20 5 "標題"  ; 繪製指定寬度 20、高度 5 的方塊
- BOX "方塊" =     ; 繪製雙線外框的方塊
- BOX "方塊" =)    ; 結尾加「)」代表圓角外框

可用的外框風格：- = + A -- ++ --- +++ ---- ++++

## FILL 與 INSET（填滿與置中）指令

```
Fill（文字填滿）    Inset（文字置中）
┌──────────────────┐ ┌──────────────────┐
│f                 │ │i                 │
│                  │ │                  │
│                  │ │                  │
│                  │ │                  │
└──────────────────┘ └──────────────────┘
```

- 將游標移至「f」位置。
- 按下 ESC，輸入「FILL <文字內容>」並按下 Enter，文字將自動填滿方塊。
- 將游標移至「i」位置。
- 按下 ESC，輸入「INSET <文字內容>」並按下 Enter，文字將在方塊內置中對齊。

## 組合指令與重複執行

您可以在 ESC 指令列中組合多個 LOGO 語法：

- BOX DATE             ; 在方塊中自動填入當前日期
- BOX DATE =)          ; 繪製圓角雙線的日期方塊
- REPEAT 3 [BOX "hi"]  ; 連續繪製 3 個方塊

## 文字轉換

- 選取任意文字範圍。
- 按下 F1 開啟選單。
- 選擇「選擇範圍」選單中的文字轉換功能。

## 行內執行指令

除了按下 ESC 開啟指令列之外，您也可以直接在文章中的任一行按下 ^Q（或 F2）直接執行該行指令。

試試看游標移到以下幾行，按下 ^Q 執行文字轉換：

move end newline type tohiragana Sakura      ; 請按下 ^Q
move end newline type tokatakana Ramen       ; 請按下 ^Q
move end newline type toromaji ラメン        ; 請按下 ^Q
move end newline type tohant 简体中文转繁体  ; 請按下 ^Q
move end newline type tohans 繁體中文轉簡體  ; 請按下 ^Q
move end newline box "Zago rocks" se newline ; 請按下 ^Q

## 更多強大功能

zago 內建完整的 Editor LOGO 直譯引擎與純文字排版工具，能將終端機變成兼具文字編輯與架構繪圖的畫布。

欲查詢更多進階指令，可在 ESC 指令列輸入「help-cmd」或「help-key」。

試著輸入 `dir` 瀏覽工作區，探索更多範例。
